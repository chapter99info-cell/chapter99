# Photography assets (V2 gate)

Put WebP/AVIF files here only after written permission. Copy approved files to `public/portfolio/approved/` and list them in `manifest.json` and `rights.txt`.

Format of `rights.txt`:

```
filename | shop name or "own work" | permission yes/no | may name shop yes/no
```

Any image with permission = no, or missing from this file, is excluded from the live page.
